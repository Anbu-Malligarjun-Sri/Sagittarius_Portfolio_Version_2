# Sagittariuz

> **Less friction. More discovery.**

![Sagittariuz portfolio homepage](public/images/BG_for_readme/Sagittariuz%20portfolio%20frontpage%28compressed%29.png)

Sagittariuz is a young software and AI company, started in 2026. We are here for a simple reason: useful technology should make hard, repetitive work easier, so people can spend more time thinking, learning, and discovering.

We are especially interested in the questions faced by researchers and students across science, technology, engineering, and mathematics. Our aim is to build thoughtful AI tools that work alongside people—with practical help, clear limits, and respect for the human judgment behind the work.

We are early in that work. This portfolio shares what we are exploring and building as we learn. We would rather show our progress honestly than claim more than we have done.

## This portfolio

The site brings together our direction, services, working process, selected projects, and team. It is built with Next.js, React, TypeScript, and Tailwind CSS, with interactive visual work using tools such as Three.js and GSAP.

## Run locally

Use the committed npm lockfile to install dependencies and start the development server:

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build and deploy

```bash
npm run build
npm run start
```

The production build uses Webpack. The repository's `vercel.json` configures Vercel to install with `npm ci` and build with `npm run build`.
